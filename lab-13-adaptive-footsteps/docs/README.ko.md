# 측정 상태로 발 위치 조정

[English](README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md)

Lab 9는 발 위치를 고정한 채 CoM과 wrench를 재계획합니다. 이 실습에서는 측정 DCM으로 미래 착지점을 바꾸되 접촉 순서와 시간은 유지합니다.

## 제한된 착지점 보정

`step_adjustment.py`는 각 Swing의 45% 시점에 DCM 오차가 8 mm를 넘으면 보정합니다. 목적함수는 `||delta − exp(omega·remaining)·error||² + ||delta||²`입니다. 제약 없는 최소점을 rectangle에 투영해 작은 convex QP를 풉니다. 보정은 축별 ±4 cm, 전방 도달 범위 −2…20 cm, 보폭 너비 14…24 cm로 제한합니다.

Quintic 경계값 궤적은 현재 reference 위치·속도·가속도를 보존하고 새 착지점에서 정지하도록 연결합니다. 수직 극값이 endpoint 지면 reference 아래로 내려가지 않는지 확인합니다. 이후 착지점도 일관되게 옮기고 DCM reference를 다시 만듭니다. 이는 위치 조정 정책이며 발 위치·시간 동시 최적화는 아닙니다. 상태는 시뮬레이터에서 얻습니다.

2. `adaptive_walk.py`에서 0·±10·±20 N 횡방향 외란을 0.15초 가하는 동일 조건으로 고정/적응형 모드를 비교하세요.
3. [데이터](../GALLERY.ko.md)의 조정 시점·이전/새 착지점·제약을 살펴보세요. 어떤 외란에서는 보정하지 않고 어떤 경우에는 한계까지 조정하는 이유를 설명하세요.

착지 정확도·관절 한계·복구 움직임을 함께 비교하세요. DCM 오차는 각 정책의 reference 기준이므로 값이 작다는 이유만으로 복구 성능이 더 좋다고 판단할 수 없습니다.
